# Skill

**Skill** is a modular, reusable set of instructions and toolkits that extend the model's capabilities or provide it with additional knowledge.
Configure Skills by adding Skill folders containing a **SKILL.md** and optional resource files to the `\skill` directory. Skills can be loaded by Momoka on demand or manually loaded via commands.

You can type /command in the CLI interface to load Skill, for example:
```bash
/skill-creator
```

For more information, please refer to [here](https://platform.claude.com/docs/zh-CN/agents-and-tools/agent-skills/).
